# The Best Meal You Ever Had

Entry for [The Best Meal You Ever Had](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85) on make.fun.

`main.ts` writes a single sentence (at most 200 characters) about the best meal ever had to `entry.txt` — no title, no explanation, just the sentence standing alone.

## Run

```sh
node main.ts
```

With a custom output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
